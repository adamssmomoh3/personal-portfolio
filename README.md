# Adams S Momoh - Personal Portfolio

A modern, responsive personal portfolio website showcasing the journey of a web developer from Sierra Leone.

## 🌟 Features

- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Dark Mode Toggle**: Switch between light and dark themes with preference persistence
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, smooth scrolling, and fade-in animations
- **Project Showcase**: Detailed project cards with technology tags and links
- **Professional CV**: Downloadable/printable resume page
- **Contact Integration**: Contact form with FormSubmit integration and Google Maps
- **Performance Optimized**: Fast loading with optimized images and CSS

## 📁 Project Structure

```
├── index.html          # Home page

```

## 🎨 Design Features

### Color Scheme
- **Light Mode**: Clean whites and blues with professional accents
- **Dark Mode**: Rich blacks and grays with consistent branding

### Typography
- **Primary Font**: Roboto (300, 400, 700 weights)
- **Icons**: Font Awesome 6.0 for consistent iconography

### Responsive Breakpoints
- **Desktop**: 1024px and up
- **Tablet**: 768px to 1023px
- **Mobile**: Up to 767px

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with accessibility considerations
- **CSS3**: Modern CSS with Flexbox, Grid, and CSS Variables
- **Vanilla JavaScript**: Pure JS for interactivity and theme management
- **Font Awesome**: Icon library
- **Google Fonts**: Typography
- **FormSubmit**: Contact form handling
